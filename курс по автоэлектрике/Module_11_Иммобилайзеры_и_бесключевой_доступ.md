# Модуль 11. Иммобилайзеры и системы бесключевого доступа

## Ликбез

Иммобилайзер — это электронная противоугонная система, которая предотвращает запуск двигателя без правильного ключа. Современные системы стали настолько сложными, что справляются с ними только специалисты.

### Принцип работы

1. Водитель вставляет ключ в замок зажигания или подносит ключ к автомобилю.
2. Антенна замка считывает код из чипа в ключе (passive transponder) или активный ключ передает код сам.
3. Сигнал передается на ЭБУ двигателя или на отдельный блок иммобилайзера.
4. ЭБУ сравнивает полученный код с сохраненным.
5. Если коды совпадают — ЭБУ разрешает запуск (отключается блокировка стартера или топливного насоса).
6. Если коды не совпадают — двигатель запустится, но сразу остановится.

### Типы иммобилайзеров

**Встроенные в ЭБУ (engine immobilizer):**
- Самый распространенный тип
- ЭБУ содержит «секретный» код
- Ключ содержит transponder chip
- При несовпадении — ЭБУ не открывает форсунки

**Отдельный блок:**
- Может быть подключен к CAN-шине или K-Line
- Часто в европейских авто (VW, BMW)

**CAN-based:**
- Обмен данными через CAN-шину
- Более сложный, но удобный для интеграции

### Технологии идентификации

- **Fixed code:** статический код (легко взломать)
- **Rolling code (rolling code, hopping code):** код меняется каждый раз (плюс — безопасность)
- **Challenge-Response:** ЭБУ отправляет challenge, ключ отвечает с вычисленным ответом (AES encryption)
- **DST (Data Secure Transmission):** шифрование на основе ключа

### Форматы ключей

- **Passive chip (ID chip):** не требует батареи, энергия от электромагнитного поля антенны
- **Active key (с батареей):** самостоятельная передача сигнала на дальнем расстоянии
- **Smart Key (keyless entry):** автомобиль определяет ключ в салоне, достаточно нажать кнопку Start/Stop
- **Key Card (NFC):** карта, которую прикладывают к специальной зоне (как Tesla)
- **Phone as a Key (UWB/Bluetooth):** смартфон как ключ

## Историческая справка

### От механических замков к chips

- **1900-е** — Механические замки с уникальным профилем ключа.
- **1980-е** — Первые электронные иммобилайзеры (радиочастотные).
- **1990-е** — Появление transponder chips (Texas Instruments, Temic).
- **1994** — Mercedes-Benz первым оснащает автомобили иммобилайзером.
- **1995** — Volkswagen Transporter с иммобилайзером (первый массовый европейский авто).
- **1998** — Европейский стандарт ECE-R116 требует иммобилайзера.
- **2000-е** — Rolling code + AES шифрование.
- **2010-е** — Бесключевой доступ (keyless entry) с NFC и Bluetooth.
- **2015-е** — UWB (Ultra-Wideband) ключи для точного позиционирования.
- **2020-е** — Мобильные ключи, распознавание лица, голоса, отпечатков.

## Нестандартные решения вендоров

### 1. Tesla — Phone as a Key (Bluetooth Low Energy)

Tesla использует **BLE (Bluetooth Low Energy)** для связи ключа (смартфона) с автомобилем. При подходе машина разблокируется автоматически. Ключ «запоминается» в автомобиле и в облаке. Можно разделить доступы (owner, driver, guest).

### 2. BMW — NFC Key Card

BMW использует **NFC-карту** (Digital Key) в смартфоне (через приложение) или физическую карту. Карту можно приложить к зоне на центральной консоли. Водитель не должен носить ключ — достаточно смартфона.

### 3. Mercedes-Benz — DIGITAL KEY + NFC + UWB

Mercedes использует **NFC + UWB (Ultra-Wideband)** для точного позиционирования ключа. Система работает до 30 метров, не боится перехвата. Можно открыть машину, просто подойдя к ней.

### 4. Audi — Advanced Key with GPS

Audi использует **GPS-трекинг ключа**. Если ключ потерян, его можно найти через приложение. Также ключ может **автоматически открывать машину** при приближении (защита от перехвата сигнала).

### 5. Volvo — Volvo On Call + Digital Key

Volvo использует **облачный сервис Volvo On Call**, который позволяет:
- Открывать/закрывать машину через приложение
- Запускать двигатель удаленно
- Отслеживать местоположение
- Вызывать помощь при аварии (eCall)

### 6. Hyundai / Genesis — Digital Key 2.0

Hyundai использует **цифровой ключ**, привязанный к Apple Wallet и Samsung Pay. Ключ можно передавать другим пользователям через облако, с ограничением по времени и скорости.

### 7. Ford — Passive Entry / Passive Start + FordPass

Ford использует **систему Passive Entry/Start**, которая определяет ключ в салоне через низкочастотную антенну. Через приложение FordPass можно удаленно запускать двигатель, открывать двери, отслеживать местоположение.

### 8. GM — Passive Keyless Entry and Push-to-Start

General Motors использует **PKE (Passive Keyless Entry)** с низкочастотной антенной в дверях. При подходе с ключом в кармане двери разблокируются. Кнопка Start/Stop запускает двигатель.

### 9. Porsche — Porsche Connect + Digital Key

Porsche использует **цифровой ключ** через приложение Porsche Connect. Можно открыть машину, запустить двигатель, настроить климат. Также есть **физический ключ** с NFC.

### 10. Land Rover — Activity Key

Land Rover предлагает **водонепроницаемый браслет Activity Key**, который работает как основной ключ для активного отдыха (плавание, бег, походы). Браслет использует NFC/RFID и привязан к автомобилю.

## Практические задания

1. Определите тип иммобилайзера по шильдику (встроенный, отдельный блок, CAN-based).
2. Снимите сигнал с антенны замка зажигания и определите частоту (125 кГц для passive transponder).
3. С помощью OBD-II сканера определите статус иммобилайзера (в некоторых машинах).
4. Изучите структуру rolling code и объясните, почему он безопаснее fixed code.
5. Продемонстрируйте работу бесключевого доступа: подойдите к машине, откройте дверь, запустите двигатель без ключа.
6. **Новое:** Проведите диагностику иммобилайзера: чтение статуса, проверка антенны, считывание/запись ключей через программатор.
7. **Новое:** Выполните программирование/регистрацию новых ключей (переключатель зажигания, OBD, программатор).
8. **Новое:** Диагностика системы бесключевого доступа (Keyless Entry/Go): антенны LF/UWB, датчики дверей, кнопка Start/Stop.
9. **Новое:** Работа с программаторами ключей (Xhorse VVDI, Autel IM508/IM608, CGDI, Lonsdor) — чтение/запись чипов, генерация ключей.
10. **Новое:** Устранение неисправностей: потеря всех ключей, ошибка "Key Not Detected", сбой синхронизации ЭБУ-иммобилайзер.

## Практические навыки: диагностика и программирование иммобилайзеров

### 1. Диагностика иммобилайзера (пошаговый алгоритм)

**Симптомы неисправности иммобилайзера:**
- Двигатель не заводится (стартер крутит, но нет зажигания/впрыска)
- Заводится и сразу глохнет (1–3 сек)
- Индикатор иммобилайзера мигает/горит на приборке (ключ/замочек/कार+ключ)
- Ошибка "Key Not Detected" / "Immobilizer Active"
- Работает только один ключ, второй не работает

**Алгоритм диагностики:**

**Этап 1: Базовая проверка (без сканера)**
1. **Проверьте второй ключ** — если работает, проблема в ключе (чип, батарея, корпус)
2. **Индикатор на приборке:** при включении зажигания должен погаснуть через 1–3 сек. Если мигает/горит — иммобилайзер не распознал ключ
3. **Проверка батареи ключа (если активный):** замена CR2032/CR2450, проверка напряжения (>2.8В)
4. **Визуально:** корпус ключа (трещины, попадание воды), лезвие (износ), антенна замка (оксиды)

**Этап 2: Сканер (OBD-II / бренд-специфичный)**
- Подключите сканер → Immobilizer / Engine ECU → Read Codes / Live Data
- **Ключевые параметры Live Data:**
  - Key Status: Valid / Invalid / Not Detected / Learning
  - Key ID / Number of Keys Learned
  - Transponder Signal Strength (RSSI)
  - Antenna Status: OK / Open / Short
  - Immobilizer Status: Armed / Disarmed / Learning Mode
- **Типичные DTC:**
  - B1xxx (Body/Immobilizer): B1111, B1234, B2101 — неисправность антенны, чипа, ЭБУ
  - P0513, P0633 — Incorrect Immobilizer Key / Immobilizer Key Not Programmed
  - U0100, U0140 — потеря связи с иммобилайзером/BCM

**Этап 3: Проверка антенны замка (Ring Antenna / Exciter Coil)**
- Расположение: вокруг замка зажигания (механический ключ) или в ручке/консоли (keyless)
- Частота: **125 кГц** (LF — Low Frequency) для пассивных транспондеров
- Проверка осциллографом: подключите щуп к одному из выводов антенны (параллельно)
  - Должен быть виден пакет импульсов 125 кГц при включении зажигания / при приближении ключа
  - Амплитуда: 10–50 В (зависит от конструкции)
- Мультиметром: сопротивление катушки антенны **1–5 Ом** (обрыв = ��, КЗ = 0)

**Этап 4: Проверка линии связи иммобилайзера**
- **K-Line (ISO 9141 / KWP2000):** одиночный провод, 10.4 кбод
- **CAN-шина (ISO 15765):** CAN-H / CAN-L между ЭБУ и иммобилайзером (или внутри ЭБУ)
- Проверка: сканером — есть ли связь, нет ли ошибок U-кодов

### 2. Программирование / регистрация ключей

**Способы программирования (зависит от бренда/модели):**

| Способ | Описание | Инструменты |
|--------|----------|-------------|
| **OBD-II (On-Board Programming)** | Через диагностический разъем, сканером | Бренд-сканер (ODIS, Xentry, ISTA, Techstream, GDS, IDS) или мульти-бренд (Autel IM508/IM608, Xhorse VVDI2, Launch X431 IMMO) |
| **On-Board Procedure (без сканера)** | Последовательность действий с ключами/зажиганием | Только для старых моделей (Ford PATS, GM VATS, некоторые Toyota/Honda) |
| **Bench / EEPROM / Flash** | Снятие ЭБУ/иммобилайзера, чтение/запись памяти программатором | Xhorse VVDI Prog, CGDI Prog, UPA USB, RT809H, ChipProg |
| **Программатор чипов (только ключ)** | Чтение/запись транспондера (ID46, ID47, ID48, ID4A, ID8C, ID8E, Temic, Megamos, Philips Crypto) | Xhorse VVDI Mini Key Tool, Autel IM508, CGDI Prog, Lonsdor K518ISE |

**Типичная процедура OBD (пример VAG Immo4/5):**
1. Подключите сканер (ODIS/VCDS) → Immobilizer → Adaptation / Key Adaptation
2. Введите PIN-код (SKC) — 4-5 значный код (из базы по VIN, или изъятие из ЭБУ/BCM)
3. Выберите "Add Key" / "Learn Key"
4. Поднесите новый ключ к антенне (или вставьте в замок) → ожидание подтверждения
5. Повторите для всех ключей (обычно макс. 8 ключей)
6. Проверка: запуск двигателя каждым ключом

**PIN-код (SKC / IMMO Code / Security Code):**
- 4–5 значный код доступа к программированию
- Источники: дилерская база по VIN, специализированные сервисы (по VIN/дампу ЭБУ), извлечение из памяти ЭБУ/BCM (EEPROM/Flash)
- Без PIN-кода программирование через OBD невозможно (кроме бенч-метода)

**Копирование ключей (Cloning):**
- Чтение оригинального ключа → запись в пустой чип (ID46/47/48/4D/4E/8C/8E)
- Работает для: Texas Instruments (4C/4D/4E), Philips Crypto (ID46/47/48), Megamos (ID48), Temic (ID11/12/13)
- **Не работает для:** последних поколений (ID4A/4B/8C/8E с Rolling Code v2/v3, AES-128) — требуется OBD программирование

### 3. Система бесключевого доступа (Keyless Entry / Passive Entry / Smart Key)

**Архитектура:**
- **LF антенны (125 кГц):** в ручках дверей (внешние), в салоне (внутренние), в багажнике — опрос ключа при касании/приближении
- **UWB антенны (6–8 ГГц):** точное позиционирование (Mercedes, BMW, Tesla Model 3/Y, Apple CarKey) — точность до 10 см
- **BLE (Bluetooth Low Energy):** связь с телефоном (Tesla, Hyundai, Lincoln, BMW Digital Key)
- **NFC (13.56 МГц):** карта/телефон у консоли (Tesla Key Card, BMW NFC Key Card)
- **Ключ (FOB):** активный (батарея CR2032) — передает rolling code на 315/433/868 МГц (RF) + LF ответ на вызов

**Диагностика Keyless Entry:**

| Симптом | Причина | Проверка |
|---------|---------|----------|
| Не открывается по ручке | LF антенна в ручке, проводка, модуль двери, БК | Сканер: Live Data LF антенны, актуатор-тест разблокировки |
| Не работает дистанционно (брелок) | Батарея ключа, RF приемник, антенна RF, брелок | Замена батареи, проверка RF сигнала (RF метр/анализатор спектра) |
| "Key Not Detected" в салоне | LF/UWB внутренние антенны, ключ, БК | Сканер: Live Data Key Status, проверка LF антенн в салоне |
| Не запускается кнопкой Start | Антенна в зоне старта, брелок, БК, замок зажигания | Сканер: Start Button Status, Key Validation |
| Не работает NFC карта/телефон | NFC антенна (консоль), настройки телефона | Проверка NFC тега, приложение (Tesla/BMW/MyHyundai) |

**Антенны LF (125 кГц) — проверка осциллографом:**
- Сигнал вызова (challenge) от БК → антенна излучает 125 кГц → ключ отвечает rolling code на RF (315/433/868 МГц)
- На осциллограмме антенны: пакеты 125 кГц при касании ручки / приближении к авто

**UWB (Ultra-Wideband) — диагностика:**
- Требует спец. измерителя (UWB анализатор спектра / детектор импульсов)
- Сканер: Live Data UWB Anchor Status, Distance Measurement, Angle of Arrival
- Калибровка: после замены UWB модулей/антенн — сканером "UWB Calibration"

| Программатор | Поддерживаемые чипы | Особенности |
|--------------|---------------------|-------------|
| **Xhorse VVDI2 / VVDI Mini Key Tool / Key Tool Max** | 4C/4D/4E, 46/47/48/4A/4B/8C/8E, Temic, Megamos, Philips, ID46/47/48/4A/8C/8E, Toyota G/H, Hyundai/Kia | WiFi/Bluetooth, генерация ключей по VIN, OBD адаптер, часто обновляется |

**Рабочий процесс (пример Xhorse VVDI2 + Key Tool Max):**
1. Определите тип чипа ключа (по разъему, внешнему виду, автоопределением программатора)
2. **Read Key:** прочитайте оригинальный ключ → сохраните дамп
3. **Generate Key:** выберите марку/модель/год → сгенерируйте данные для нового ключа (или клонируйте из дампа)
4. **Write Key:** запишите в новый чип (пустой брелок / чип)
5. **Program via OBD:** подключите OBD адаптер → выберите марку → Key Learning → введите PIN → обучение ключа
6. **Test:** проверьте запуск двигателем, работу брелока, Keyless Entry

### 5. Сложные случаи: потеря всех ключей (All Keys Lost)

**Ситуация:** у клиента нет ни одного рабочего ключа.

**Решения:**
1. **OBD + PIN-код (если известен):**
   - Получите PIN-код (SKC) по VIN (дилер, базы, сервисы онлайн) или извлеките из ЭБУ/BCM (Bench/EEPROM)
   - Подключите сканер → Immobilizer → All Keys Lost / Erase Keys → введите PIN → обучение новых ключей
   - Доступно для: VAG (Immo3/4/5), BMW (CAS/FEM/BDC), Mercedes (EZS/ELV), Ford, Toyota, Hyundai/Kia, GM

2. **Bench / EEPROM / Flash (если PIN неизвестен или OBD заблокирован):**
   - Снимите ЭБУ двигателя / BCM / Иммобилайзер / CAS / EZS
   - Прочитайте EEPROM/Flash (95xxx, 25xxx, 93xxx, SPC56, MPC5xxx, TriCore) программатором (VVDI Prog, CGDI Prog, UPA, RT809H)
   - Найдите/рассчитайте PIN-код из дампа (спец. софт: VVDI Prog Calculator, CGDI Calculator, 온лайн сервисы)
   - Прошейте новые ключи в дамп (или сгенерируйте Virgin дамп) → запишите обратно
   - Установите модуль → обучение ключей через OBD (теперь PIN известен)

3. **Замена модулей (последний случай):**
   - Закажите новый ЭБУ/BCC/Иммобилайзер/Ключи у дилера по VIN (Pre-coded / Virgin)
   - Установите → обучение ключей (PIN часто не нужен для Virgin модулей)

### 6. Типичные неисправности и коды

| Симптом | DTC (примеры) | Причина | Решение |
|---------|---------------|---------|---------|
| "Key Not Detected" | B1111, B1234, P0513 | Антенна LF, ключ (чип/батарея), БК | Проверка антенны, замена ключа/батареи |
| Двигатель заводится и глохнет | P0513, P0633, B1234 | Чип не прочитан, rolling code рассинхрон | Переобучение ключа, проверка антенны |
| Один ключ работает, другой нет | — | Чип второго ключа, батарея, корпус | Замена ключа/батареи, переобучение |
| Keyless не работает (ручки) | B1xxx (Door Handle Antenna) | LF антенна в ручке, проводка в камаре двери | Проводка в камаре (разомкни), антенна, модуль двери |
| "Key Not Detected" в салоне | B1xxx (Interior Antenna) | Внутренняя LF/UWB антенна, БК | Проверка антенн в салоне, сканер |
| Ошибка после замены ЭБУ | P0633, U0100 | Не проведена адаптация иммобилайзера | Адаптация ЭБУ + иммобилайзера (сканер + PIN) |
| Брелок не работает дистанционно | — | Батарея CR2032, RF приемник, брелок | Замена батареи, проверка RF сигнала |

### 6. Работа с PIN-кодами (Security Access)

**Источники PIN-кода (SKC / IMMO Code / Security Code):**
1. **Дилерская база по VIN** (официально, платно, требует подтверждения владения)
2. **Специализированные онлайн-сервисы** (по VIN + фото документов / дампу ЭБУ) — платные
3. **Извлечение из дампа ЭБУ/BCM/CAS/EZS** (Bench/EEPROM) — программатор + калькулятор (VVDI Prog Calculator, CGDI Calculator, Abrites, PCMFlash)
4. **Из меню сканера** (некоторые бренды показывают PIN в Live Data после входа в Security Access)

**Важно:** Не пытайтесь подбирать PIN — после 3–5 неверных попыток модуль блокируется на время (от 10 мин до 24 ч) или требует перепрограммирования!

### Безопасность и юридические аспекты

1. **Законность:** программирование ключей разрешено только легальному владельцу (подтверждение: ПТС/СТС, паспорт, договор купли-продажи)
2. **Документирование:** зафиксируйте VIN, номер ключа, дату, действие (добавление/удаление/замена), подпись клиента
3. **Удаление ключей:** при утере/краже ключа обязательно удалите его из памяти иммобилайзера (Erase Keys / Delete Key)
4. **Не используйте "универсальные" ключи/чипы** без понимания протокола — риск повреждения иммобилайзера
5. **HV/EV (Tesla, Hyundai, Porsche Taycan и др.):** программирование ключей может требовать высоковольтовой безопасности (Service Disconnect) и специфического ПО
