# Модуль 11. Иммобилайзеры и системы бесключевого доступа

## Ликбез

Иммобилайзер — это электронная противоугонная система, которая предотвращает запуск двигателя без правильного ключа. Современные системы стали настолько сложными, что справляются с ними только специалисты.

### Принцип работы

1. Водитель вставляет ключ в замок зажигания или подносит ключ к автомобилю.
2. Антенна замка считывает код из чипа в ключе (passive transponder) или активный ключ передает код сам.
3. Сигнал передается на ЭБУ двигателя или на отдельный блок иммобилайзера.
4. ЭБУ сравнивает полученный код с сохраненным.
5. Если коды совпадают — ЭБУ разрешает запуск (отключается блокировка стартера или топливного насоса).
6. Если коды не совпадают — двигатель запустится, но сразу остановится.

### Типы иммобилайзеров

**Встроенные в ЭБУ (engine immobilizer):**
- Самый распространенный тип
- ЭБУ содержит «секретный» код
- Ключ содержит transponder chip
- При несовпадении — ЭБУ не открывает форсунки

**Отдельный блок:**
- Может быть подключен к CAN-шине или K-Line
- Часто в европейских авто (VW, BMW)

**CAN-based:**
- Обмен данными через CAN-шину
- Более сложный, но удобный для интеграции

### Технологии идентификации

- **Fixed code:** статический код (легко взломать)
- **Rolling code (rolling code, hopping code):** код меняется каждый раз (плюс — безопасность)
- **Challenge-Response:** ЭБУ отправляет challenge, ключ отвечает с вычисленным ответом (AES encryption)
- **DST (Data Secure Transmission):** шифрование на основе ключа

### Форматы ключей

- **Passive chip (ID chip):** не требует батареи, энергия от электромагнитного поля антенны
- **Active key (с батареей):** самостоятельная передача сигнала на дальнем расстоянии
- **Smart Key (keyless entry):** автомобиль определяет ключ в салоне, достаточно нажать кнопку Start/Stop
- **Key Card (NFC):** карта, которую прикладывают к специальной зоне (как Tesla)
- **Phone as a Key (UWB/Bluetooth):** смартфон как ключ

## Историческая справка

### От механических замков к chips

- **1900-е** — Механические замки с уникальным профилем ключа.
- **1980-е** — Первые электронные иммобилайзеры (радиочастотные).
- **1990-е** — Появление transponder chips (Texas Instruments, Temic).
- **1994** — Mercedes-Benz первым оснащает автомобили иммобилайзером.
- **1995** — Volkswagen Transporter с иммобилайзером (первый массовый европейский авто).
- **1998** — Европейский стандарт ECE-R116 требует иммобилайзера.
- **2000-е** — Rolling code + AES шифрование.
- **2010-е** — Бесключевой доступ (keyless entry) с NFC и Bluetooth.
- **2015-е** — UWB (Ultra-Wideband) ключи для точного позиционирования.
- **2020-е** — Мобильные ключи, распознавание лица, голоса, отпечатков.

## Нестандартные решения вендоров

### 1. Tesla — Phone as a Key (Bluetooth Low Energy)

Tesla использует **BLE (Bluetooth Low Energy)** для связи ключа (смартфона) с автомобилем. При подходе машина разблокируется автоматически. Ключ «запоминается» в автомобиле и в облаке. Можно разделить доступы (owner, driver, guest).

### 2. BMW — NFC Key Card

BMW использует **NFC-карту** (Digital Key) в смартфоне (через приложение) или физическую карту. Карту можно приложить к зоне на центральной консоли. Водитель не должен носить ключ — достаточно смартфона.

### 3. Mercedes-Benz — DIGITAL KEY + NFC + UWB

Mercedes использует **NFC + UWB (Ultra-Wideband)** для точного позиционирования ключа. Система работает до 30 метров, не боится перехвата. Можно открыть машину, просто подойдя к ней.

### 4. Audi — Advanced Key with GPS

Audi использует **GPS-трекинг ключа**. Если ключ потерян, его можно найти через приложение. Также ключ может **автоматически открывать машину** при приближении (защита от перехвата сигнала).

### 5. Volvo — Volvo On Call + Digital Key

Volvo использует **облачный сервис Volvo On Call**, который позволяет:
- Открывать/закрывать машину через приложение
- Запускать двигатель удаленно
- Отслеживать местоположение
- Вызывать помощь при аварии (eCall)

### 6. Hyundai / Genesis — Digital Key 2.0

Hyundai использует **цифровой ключ**, привязанный к Apple Wallet и Samsung Pay. Ключ можно передавать другим пользователям через облако, с ограничением по времени и скорости.

### 7. Ford — Passive Entry / Passive Start + FordPass

Ford использует **систему Passive Entry/Start**, которая определяет ключ в салоне через низкочастотную антенну. Через приложение FordPass можно удаленно запускать двигатель, открывать двери, отслеживать местоположение.

### 8. GM — Passive Keyless Entry and Push-to-Start

General Motors использует **PKE (Passive Keyless Entry)** с низкочастотной антенной в дверях. При подходе с ключом в кармане двери разблокируются. Кнопка Start/Stop запускает двигатель.

### 9. Porsche — Porsche Connect + Digital Key

Porsche использует **цифровой ключ** через приложение Porsche Connect. Можно открыть машину, запустить двигатель, настроить климат. Также есть **физический ключ** с NFC.

### 10. Land Rover — Activity Key

Land Rover предлагает **водонепроницаемый браслет Activity Key**, который работает как основной ключ для активного отдыха (плавание, бег, походы). Браслет использует NFC/RFID и привязан к автомобилю.

## Практические задания

1. Определите тип иммобилайзера по шильдику (встроенный, отдельный блок, CAN-based).
2. Снимите сигнал с антенны замка зажигания и определите частоту (125 кГц для passive transponder).
3. С помощью OBD-II сканера определите статус иммобилайзера (в некоторых машинах).
4. Изучите структуру rolling code и объясните, почему он безопаснее fixed code.
5. Продемонстрируйте работу бесключевого доступа: подойдите к машине, откройте дверь, запустите двигатель без ключа.
