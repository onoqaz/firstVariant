# Модуль 6. Электрооборудование кузова

## Ликбез

Электрооборудование кузова — совокупность электрических систем, обеспечивающих комфорт, безопасность и функциональность автомобиля за пределами силового агрегата.

### Система стеклоочистителя

- **Двигатель стеклоочистителя** — электродвигатель с червячным редуктором, 12В, 30–80Вт
- **Переключатель** — 3–5 скоростей + прерывистый режим (интервальный)
- **Реле** — коммутирует двигатель
- **Датчик дождя** — фоторезистор, управляет прерывистым режимом автоматически
- **Двигатель омывателя** — 12В, 10–30Вт, насос с импеллером

### Центральный замок

- **Электропривод двери** — моторчик-редуктор 12В, 10–15Вт
- **Датчики дверей** — концевые выключатели (открыто/закрыто)
- **Блок управления** — прием сигналов от брелока, управление приводами
- **Кнопки на дверях** — ручное управление

### Система блокировки и сигнализации

- **Иммобилайзер** — модуль, отключающий стартер или топливный насос при отсутствии правильного ключа
- **Охранная сигнализация** — датчики (удара, объема, объема), сирена, центральный блок
- **Дистанционный запуск** — модуль, управляющий стартером по радиосигналу

### Стеклоподъемники и зеркала

- **Электродвигатель стеклоподъемника** — 12В, 20–40Вт, с редуктором и концевиками
- **Электропривод зеркала** — 2 двигателя на каждое зеркало (вертикаль/горизонталь)
- **Датчики положения** — потенциометры или энкодеры
- **Автоматика** — память положения, антипридавливание (обрыв при препятствии)

## Историческая справка

### От ручного открывания к автоматике

- **1900-е** — Все механическое: ручные стеклоподъемники, физические замки
- **1920-е** — Появление первого электрического стеклоочистителя (Charlotte Bridgewood, 1917).
- **1930-е** — Электрические стеклоподъемники в Cadillac (1937).
- **1950-е** — Центральный замок становится опцией (Packard, 1956).
- **1960-е** — Электрические зеркала заднего вида в Cadillac.
- **1970-е** — Электронные блоки управления (ECU) для замков.
- **1980-е** — Иммобилайзеры (первый в Volkswagen Transporter, 1988).
- **1990-е** — Сигнализации с дистанционным запуском, бесключевой доступ.
- **2000-е** — Электронные ключи с чипом, автоматические стеклоподъемники с памятью.
- **2010-е** — Бесключевой доступ (keyless entry), биометрические системы.
- **2020-е** — Ультразвуковые датчики, камеры, мобильные ключи.

### Эволюция стеклоочистителя

- **1896** — Первый ручной стеклоочиститель (Mary Anderson).
- **1917** — Электрический стеклоочиститель (Charlotte Bridgewood).
- **1920-е** — Пневматические стеклоочистители.
- **1930-е** — Двухскоростные электрические.
- **1960-е** — Прерывистый режим (intermittent).
- **1980-е** — Датчик дождя (Citroën CX).
- **2000-е** — Адаптивные стеклоочистители (Audi, Mercedes).
- **2020-е** — Камеры + AI для управления стеклоочистителем (Tesla Autopilot).

## Нестандартные решения вендоров

### 1. Tesla Model S/X — бесключевой доступ + телефон как ключ

Tesla использует **Bluetooth-ключ** в смартфоне + NFC-карту. При приближении машина автоматически разблокирует двери, зажигание включается, зеркала раскладываются. При удалении — блокирует, зажигание выключается. Нет физического ключа в классическом понимании.

### 2. Mercedes-Benz S-Class — MULTIBEAM LED + DIGITAL LIGHT

В фарах S-Class используется **псевдоним для фара** — 84 светодиода, управляемых отдельно. При повороте фары «заглядывают» за угол, а при встречном транспорте «темная зона» следует за ним. Цифровое освещение позволяет проецировать знаки на асфальт.

### 3. BMW 7 Series — Gesture Control

BMW использует **жестовое управление** в салоне: вращение пальца для громкости, указание для навигации. Это не прямое электрооборудование кузова, но часть общей электроники. Система работает через камеру в потолке салона.

### 4. Audi A8 — интеллектуальный стеклоочиститель с камерой

Audi A8 использует **камеру на лобовом стекле** для управления стеклоочистителями. Если дождь сильный — скорость повышается, если капля одна — прерывистый режим. При ярком солнце — автоматически включается ближний свет.

### 5. Land Rover Defender — интеллектуальный центральный замок с NFC

Land Rover Defender (2020) использует **NFC-ключ** в смартфоне. При касании двери ключом — открытие. Также есть **Activity Key** — водонепроницаемый браслет для активного отдыха.

### 6. Volvo — автоматическое складывание зеркал при парковке

Volvo использует **радар парковки** для автоматического складывания боковых зеркал. При обнаружении препятствия сзади зеркала складываются, чтобы не задеть проезжающую машину.

### 7. Cadillac Escalade — Intellibeam + Adaptive Cruise

Cadillac использует **систему Intellibeam**, которая автоматически переключает между ближним и дальним светом на основе радара и камеры. При встречном транспорте или впереди идущей машине фары переключаются на ближний свет без участия водителя.

### 8. Genesis GV80 — Blind-Spot View Monitor + 3D-панорама

Genesis использует **камеры в боковых зеркалах** для отображения 3D-панорамы на центральном экране. При включении поворотника на экране появляется изображение слепой зоны с перспективой, как будто водитель смотрит через зеркало.

### 9. Toyota Crown — electrochromic зеркала

Toyota использует **электрохромные зеркала**, которые затемняются автоматически при ярком свете сзади. Это аналог polaroid-фильтра, управляемого напряжением.

### 10. Lexus LS — мультифункциональное зеркало с дисплеем

Lexus LS использует **полноэкранное LCD-зеркало**, которое показывает изображение от камеры, установленной сзади. При ярком свете автоматически повышает яркость изображения, чтобы водитель видел, что происходит сзади.

## Практические задания

1. Определите тип стеклоочистителя по звуку (пневматический, электрический, двухскоростной).
2. Замерьте ток потребления двигателя стеклоочистителя.
3. Проверьте работу концевиков двери (открыто/закрыто).
4. Снимите сигнал с датчика дождя и определите его тип (резистивный, фоторезисторный).
5. Проверьте работу стеклоподъемника с антипридавливанием (прерывистый режим).
