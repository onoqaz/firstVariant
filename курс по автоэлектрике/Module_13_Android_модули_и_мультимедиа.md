# Модуль 13. Android-модули и мультимедиа системы

## Ликбез

Android-модули — это устройства, которые подключаются к штатной мультимедийной системе автомобиля и добавляют функционал Android: навигация, YouTube, приложения, интернет.

### Типы модулей

**Universal (универсальные):**
- Подключаются через CAN-шину, LVDS, AUX, USB
- Поддерживают большинство марок (VAG, BMW, Mercedes, Toyota, Ford)
- Требуют адаптации к конкретной машине

**Марочные (Canbox, Magotan, etc.):**
- Специально для определенных марок
- Полная интеграция с CAN-шиной
- Поддержка кнопок руля, климат-контроля, камер

**Полная замена (Android Head Unit):**
- Заменяет штатное головное устройство целиком
- Подключается через разъем, идентичный штатному
- Требует адаптера к разъему и антенне

### Интерфейсы подключения

- **LVDS:** цифровой видеоинтерфейс (VGA-подобный), для экрана штатного HU
- **RGB / CVBS:** аналоговое видео для камер заднего вида
- **CAN / LIN:** управление автомобилем (кнопки руля, климат, статус дверей)
- **USB:** зарядка, AUX
- **AUX:** аналоговый звук
- **Antenna:** GPS-антенна, FM-антенна

### Функции

- Навигация (Yandex, Google Maps, OsmAnd)
- Медиа (YouTube, Spotify, VK)
- Интернет (Wi-Fi hotspot, 4G модем)
- Функции CAN (управление климатом, кнопки руля)
- Камеры (задний вид, 360°)
- OBD-II диагностика

## Историческая справка

### От кассет к Android

- **1930-е** — Первые автомобильные радиоприемники (Motorola).
- **1960-е** — Установка кассетных плейеров.
- **1980-е** — CD-чейнджеры, первые экраны.
- **1990-е** — CD-чейнджеры с экраном (Nissan, Toyota).
- **2000-е** — DVD-чейнджеры, GPS-навигация встроенная.
- **2005-е** — Bluetooth-соединение с телефоном, USB-порт.
- **2010-е** — Смартфон-интеграция (Apple CarPlay, Android Auto).
- **2012-е** — Tesla Model S с 17-дюймовым экраном (веб-браузер).
- **2014-е** — Tesla V9 software (Starbase, Netflix, YouTube).
- **2015-е** — Android-based head units ( универсальные модули).
- **2018-е** — Tesla V10 с полной интеграцией приложений.
- **2020-е** — Android Automotive OS (операционная система для автомобилей).

### Лицензирование Android Automotive

Google разрабатывает **Android Automotive OS** — отдельную ОС для автомобилей (не CarPlay). Первыми авто с Android Automotive:
- **Polestar 2** (2020)
- **Volvo EX90** (2023)
- **Honda e** (2020)
- **Chevrolet Blazer EV** (2023)
- **Hyundai Ioniq 5** (2022)

Это **встроенная ОС**, а не просто отображение телефона.

## Нестандартные решения вендоров

### 1. Tesla — центральный экран как единственный интерфейс

Tesla отказалась от всех физических кнопок и переключателей. **Весь климат-контроль, навигация, медиа, настройки** управляются через 15-дюймовый (Model S/X) или 17-дюймовый (Model 3/Y) сенсорный экран. Это радикальное решение, которое разделило пользователей на сторонников и противников.

### 2. BMW — iDrive 8 с曲面 дисплеем

BMW iDrive 8 использует **изогнутый дисплей 12.3" + 14.9"**, объединенный в единый экран под одним стеклом. Управление — **touch, iDrive Controller, voice control, gestures**. Система построена на **Linux + QNX**.

### 3. Mercedes-Benz — MBUX Hyperscreen

Mercedes EQS использует **56-дюймовый экран Hyperscreen**, состоящий из трех дисплеев под одним стеклом:
- **12.3"** приборная панель
- **17.7"** центральный экран
- **12.3"** экран пассажира

Управление — **MBUX Assistant** (голосовое AI «Hey Mercedes»), которое понимает естественную речь.

### 4. Audi — MMI Touch Response + Virtual Cockpit

Audi использует **два экрана** в центральной консоли:
- **10.1"** верхний экран (навигация, медиа)
- **8.6"** нижний экран (климат, комфорт)

Также есть **Virtual Cockpit** (12.3") на месте приборов. Управление — **touch с тактильной обратной связью**.

### 5. Volvo — Google Built-in (Android Automotive)

Volvo и Polestar первыми внедрили **Google Built-in** (Android Automotive). Это не Android Auto — это **встроенная ОС** с:
- Google Maps
- Google Assistant
- Google Play Store
- Spotify, YouTube Music

Управление голосом через Google Assistant.

### 6. Hyundai / Kia — ccOS (connected car Operating System)

Hyundai использует **ccOS** на базе Linux + Android. Система поддерживает:
- Bluetooth Phone, Apple CarPlay, Android Auto
- Удаленное управление через Bluelink
- OTA-обновления
- Голосовое управление (Hi, Genesis)

### 7. Ford — SYNC 4A с Amazon Alexa

Ford использует **SYNC 4A** с 15.5-дюймовым экраном. Система поддерживает:
- Apple CarPlay, Android Auto
- Amazon Alexa (голосовое управление)
- Удаленное управление через FordPass
- OTA-обновления

### 8. Nissan — NissanConnect с 12.3" экраном

Nissan использует **NissanConnect** с 12.3-дюймовым цифровым кластером и центральным экраном. Система поддерживает Android Auto, Apple CarPlay и навигацию.

### 9. Subaru — STARLINK с Android Auto / Apple CarPlay

Subaru использует **STARLINK** с экранами до 11.6". Система поддерживает Apple CarPlay и Android Auto, а также удаленное управление через приложение.

### 10. Toyota — Audio Multimedia с облаком

Toyota использует **Audio Multimedia** с 8- или 14-дюймовым экраном. Система поддерживает:
- Apple CarPlay, Android Auto
- Облачные навигационные карты (T-Connect)
- Обновление карт по LTE ( без USB)

## Практические задания

1. Определите тип головного устройства по разъемам (LVDS, CAN, AUX, USB).
2. Определите тип подключения к CAN-шине (двухпроводное, однопроводное LIN).
3. Проверьте работу кнопок руля через OBD-II сканер (если поддерживается).
4. Установите Android-модуль и настройте CAN-имитацию для управления климатом.
5. Проверьте работу камер заднего вида через RGB-вход.
6. **Новое:** Выполните полную установку Android-модуля: разборка магнитолы, подключение LVDS/RGB/CAN, настройка разрешения, калибровка тача.
7. **Новое:** Настройте CAN-интеграцию: кнопки руля, климат-контроль, статус дверей/РПМ/скорость, камеры 360°.
8. **Новое:** Установите и настройте CarPlay/Android Auto (проводной/беспроводной): кабели, сертификаты, настройки телефона.
9. **Новое:** Прошейте/обновите прошивку модуля: Recovery/Factory Reset, OTA, SD-карта, EDL Mode.
10. **Новое:** Диагностика неисправностей: нет картинки, нет звука, не работают кнопки руля, глюки CAN, перегрев.

## Практические навыки: установка, настройка и диагностика Android-модулей

### 1. Подготовка и выбор модуля

**Типы модулей и выбор:**
| Тип | Применение | Плюсы | Минусы |
|-----|------------|-------|--------|
| **Universal (Box)** | Подключается к штатному HU через LVDS/RGB/CAN | Сохраняет штатный экран/управление, дешевле | Ограниченная интеграция, возможны глюки CAN |
| **Brand-specific (Canbox, Magotan, Tesla-style)** | Под конкретную марку/модель | Полная интеграция CAN, кнопки руля, климат, камеры | Дороже, только под конкретный авто |
| **Android Head Unit (замена HU)** | Полная замена магнитолы | Полный Android, большой экран, гибкость | Потеря штатных функций (если не поддерживаются), сложный монтаж |

**Ключевые характеристики для выбора:**
- **CPU:** 8 ядер (Cortex-A53/A55) минимум, лучше 8×A73/A55 (Unisoc T765, Rockchip PX6/PX5, Qualcomm SDM660/6125)
- **RAM:** 4 Гб минимум, 6–8 Гб рекомендуется (Android 10/11/12/13 потребляет 2–3 Гб)
- **Storage:** 64 Гб минимум, 128 Гб+ рекомендуется (приложения + кэш карт/медиа)
- **Android version:** 10 (Q) минимум, 11/12/13 лучше (поддержка CarPlay/Android Auto, безопасность)
- **Видео входы:** LVDS (экран), RGB/CVBS (камеры), HDMI (внешний источник)
- **CAN/LIN:** поддержка конкретного протокола авто (проверяйте базу продавца по VIN)

### 2. Установка Universal Box модуля (подключение к штатному HU)

**Разборка и доступ к разъемам:**
1. Снимите штатную магнитолу (ключи для разборки панели, Torx/Torx Security для магнитолы)
2. Найдите разъемы задней части HU: **Quadlock / ISO / проприетарный** (зависит от марки)
3. Определите нужные линии по схемам (ETKA, WIS, TIS, EPC):
   - **LVDS видео:** 4–8 пар差分ных проводов (TX0–TX3, CLK) — для вывода картинки на штатный экран
   - **RGB / CVBS вход:** для камеры заднего вида (обычно 3–4 провода: Y, Pb, Pr / Video, GND)
   - **CAN-H / CAN-L:** для управления кнопками руля, климатом, статусами
   - **LIN / K-Line:** для старых авто (кнопки руля, климат)
   - **AUX / USB / AUX-IN:** звук
   - **ACC (15) / BAT (30) / GND (31):** питание
   - **Reverse (R):** сигнал задней передачи (включение камеры)
   - **Speed Pulse / RPM / Illumination:** доп. сигналы

**Монтаж Box модуля:**
1. Разместите Box в консоли/под приборкой/под сиденьем — сухое, вентилируемое место
2. Прокладка проводов: LVDS кабель (экранированный!) от Box к HU — **критично: не гните, не зажимайте, держите подальше от силовых проводов**
3. Питание: **BAT (30)** — от АКБ через предохранитель 5А; **ACC (15)** — от замка зажигания; **GND** — на кузов
4. **CAN-H/L:** подключение параллельно к шине HU (не перерезайте! используйте Т-обжим/пайку)
5. **Reverse (R):** от выключателя задней передачи / CAN / блок управления коробкой
6. **Камера заднего вида:** питание камеры от реверса, видео (RGB/CVBS) в Box, Box → LVDS в HU
7. **Микрофон:** для голосового управления/звонков — монтаж у руля/потолка

### 3. Настройка разрешения и калибровка (после включения)

**Вход в настройки (обычно: долгое нажатие Home / Menu / громкость +/−):**
1. **Display / Resolution:** установите разрешение, соответствующее штатному экрану:
   - 800×480 (WVGA) — старые экраны 6.5–7"
   - 1280×480 / 1280×720 — широкие экраны 8–10"
   - 1920×720 / 1920×1080 — Full HD экраны 10–12"
   - **Важно:** неверное разрешение = черный экран / растянутая картинка / нет тача
2. **LVDS Lane / Clock Polarity:** настройка синхронизации (обычно Auto, иногда Manual: 1/2/4 lanes, Rising/Falling edge)
3. **Touch Calibration:** калибровка сенсора (Touch Panel) — если тач не работает / смещен
   - Settings → Display → Touch Calibration → нажимайте крестики точно в центр
   - Некоторые модули требуют калибровки через ADB / инженерное меню (`*#*#4636#*#*` или `*#*#3646633#*#*`)
4. **Video Input:** настройка камеры (CVBS/RGB, NTSC/PAL, Mirror On/Off, Guidelines On/Off)
4. **CAN Settings:** выбор протокола авто (Car Model / Protocol / Brand) — выбор из базы модуля

### 4. Настройка CAN-интеграции (кнопки руля, климат, статусы)

**Типы CAN-протоколов в модулях:**
- **High-level (CAN-эмуляция штатного усилителя/процессора):** модуль "притворяется" штатным усилителем/процессором — полная интеграция
- **Low-level (CAN-сниффер):** модуль слушает шину и эмулирует нажатия кнопок — ограниченная интеграция

**Настройка (в инженерном меню / APK Car Settings / Canbox Settings):**
1. **Car Model / Protocol:** выбор авто из базы (VW Golf 7 MQB, BMW E90/F30, Mercedes NTG5, Toyota T-Connect и т.д.)
2. **Steering Wheel Controls (SWC):** обучение кнопок
   - Settings → SWC Learning → нажимайте кнопку на руле → модуль запоминает CAN ID / Data
   - Или выбор готового профиля (Volkswagen MQB, BMW EVO, Mercedes NTG5.5)
3. **Climate Control:** синхронизация с штатным климатом
   - Отображение температуры, режимов, дувления на экране Android
   - Управление с экрана → отправка CAN команд климат-блоку
4. **Vehicle Status:** отображение на экране: RPM, Speed, Fuel Level, Doors Open, Gear Position, ODO
   - Настройка: какие PID запрашивать, частота обновления
5. **360° Camera / PDC:** интеграция с штатными камерами/парктрониками
   - Входы: RGB/CVBS × 4 (Front/Rear/Left/Right) → склейка в модуле / передача на LVDS

**Тестирование CAN:**
- Нажмите кнопку на руле → сработало в Android (громкость, трек, голос)
- Измените климат на экране → сработало в авто (вентилятор, температура)
- Заведите авто → появились RPM, Speed, уровень топлива
- Включите реверс → включилась камера, включились парктроники

### 5. CarPlay / Android Auto (проводной и беспроводной)

**Проводной (Wired):**
- Кабель USB (Data + Charge) от модуля к разъему в консоли/под рулем
- Модуль должен иметь **Apple MFi сертификат** (для CarPlay) или проходить Google Certification (для Android Auto)
- Настройки: Settings → CarPlay / Android Auto → Enable → подключите телефон → доверие / разрешения

**Беспроводной (Wireless CarPlay / Wireless Android Auto):**
- Требования: модуль с **Wi-Fi 5GHz (802.11ac/ax)** + Bluetooth 5.0+ для первичного парирования
- Настройка: Settings → Wireless CarPlay/Android Auto → Pair New Device → Bluetooth пары → Wi-Fi Direct соединение
- **Важно:** не все модули поддерживают Wireless AA/CP — проверяйте спеки (обычно на Qualcomm SDM660/6125, Unisoc T765)

**Устранение неисправностей CarPlay/AA:**
- Не подключается: проверьте кабель (оригинальный Apple / качественный USB 3.0), порт USB модуля (перезагрузка модуля), настройки телефона (Ограничения → CarPlay Вкл)
- Отваливается: кабель, перегрев порта, версия iOS/Android, прошивка модуля
- Нет звука: настройки звука в телефоне/модуле, AUX/Bluetooth конфликт

### 6. Прошивка и обновление модуля

**Способы обновления:**
1. **OTA (Over-The-Air):** Settings → System Update → Check Update → Download & Install (требует Wi-Fi/4G)
2. **SD-карта / USB-флешка:** скачайте `update.zip` / `update.img` от производителя → вставьте в модуль → Settings → Local Update
3. **Recovery Mode:** выключение питания → удержание кнопки (Vol+ / Power / Reset) → вход в Recovery → Apply update from SD/USB
4. **EDL Mode (Emergency Download / 9008 Mode):** для Qualcomm/Unisoc чипов — короткое замыкание тестовых точек на плате (EDL Short) → PC + QFIL / SPD Flash Tool → прошивка `rawprogram.xml` + `patch.xml` + образы разделов (boot, dtbo, dtb, vendor, system, super)
5. **Fastboot Mode:** для разблокированного загрузчика — `fastboot flash boot boot.img`, `fastboot flash dtbo dtbo.img`, `fastboot update rom.zip`

**Риски прошивки:**
- **Brick (кирпич):** неверная прошивка, отключение питания, неверный раздел → модуль не включается
- **Потеря данных:** сброс настроек, аккаунтов, приложений (Factory Reset часто обязателен после мажорного обновления)
- **Несовместимость:** прошивка от другой ревизии платы / другой региона / другой версии экрана

**Бэкап перед прошивкой:**
- Settings → Backup & Restore → Backup to SD/USB (настройки, аккаунты, APK)
- EFS / Persist / Modem разделы (через TWRP / EDL) — критично для IMEI, Wi-Fi MAC, BT MAC, калибровки тача/экрана

### 7. Диагностика неисправностей

| Симптом | Причина | Диагностика / Решение |
|---------|---------|----------------------|
| **Черный экран / нет сигнала** | Неверное LVDS разрешение, кабель, питание экрана | Проверка LVDS кабеля (переподключение), настройка Resolution в инженерном меню, проверка 12В на экране |
| **Тач не работает / смещен** | Калибровка сбита, кабель тача, драйвер | Touch Calibration, проверка FPC кабеля тача, перепрошивка драйвера тача |
| **Нет звука / шумы** | AUX кабель, настройки микшера, заземление (ground loop) | Проверка AUX кабеля, Settings → Audio → Output, изоляция заземления (изолирующий трансформатор) |
| **Кнопки руля не работают** | CAN протокол не выбран, SWC не обучен, CAN-H/L перепутаны | Settings → Car Model / Protocol, SWC Learning, проверка CAN-H/L мультиметром |
| **Климат не управляется / не показывает** | CAN протокол климата не совпадает, LIN вместо CAN | Проверка CAN ID климата (сканером), выбор правильного протокола |
| **Камера не включается / черный экран** | Reverse сигнал не доходит, видео вход не настроен, камера неисправна | Проверка 12В на камере при R, Settings → Video Input → CVBS/RGB, Mirror |
| **CarPlay/Android Auto не подключается** | Кабель, порт USB, версия прошивки, сертификат MFi | Качественный кабель, перезагрузка модуля/телефона, обновление прошивки модуля |
| **Перегрев / перезагрузки** | Плохое охлаждение, неисправный PMIC, перегрузка по питанию | Очистка радиатора/вентилятора, проверка 12В/5В на плате, прошивка с исправлением thermique |
| **CAN ошибки / глюки авто** | Модуль забивает шину, неверный терминатор, конфликт ID | Отключение CAN модуля → проверка авто, проверка 60 Ом на шине, обновление прошивки CAN |

### 8. Инженерное меню и скрытые настройки (частые коды)

| Действие | Код / Метод |
|----------|-------------|
| Инженерное меню (MTK/Unisoc) | `*#*#3646633#*#*` или `*#*#4636#*#*` → EngineerMode |
| Инженерское меню (Qualcomm) | `*#*#228#*#*` или `*#*#7378423#*#*` (Service Menu) |
| Recovery Mode | Power + Vol Up (удержание 10 сек) → меню Recovery |
| Fastboot Mode | Power + Vol Down (удержание) → Fastboot |
| EDL Mode (9008) | Короткое замыкание EDL точек на плате + питание |
| ADB (по USB/Wi-Fi) | Settings → Developer Options → USB Debugging → `adb shell` |
| Сброс к заводу (Factory Reset) | Settings → Backup & Reset → Factory Data Reset |

### 9. Юридические аспекты и безопасность

1. **Отвлечение водителя:** видеоплееры/YouTube/браузер — только на парковке (Handbrake + P/R/N) — модуль должен блокировать видео на движении (Speed Pulse / CAN Speed = 0)
2. **Гарантия авто:** установка стороннего модуля может аннулировать гарантию на магнитолу/электрику — документально зафиксируйте установку, сохраните штатные разъемы (адаптеры без пайки)
3. **Радиочастоты:** Wi-Fi/Bluetooth/4G модули должны иметь сертификат ЕАЭС/ФСБ (для РФ)
3. **Персональные данные:** аккаунты Google/Apple, история навигации — сброс при продаже авто (Factory Reset)
4. **Безопасность питания:** питание Box модуля только через предохранитель 5–10А, заземление на кузов, никаких "наколов" проводов

### Лучшие практики установки

1. **Всегда делайте фото схем штатных разъемов** до разборки — для возврата к штатному виду
2. **Используйте адаптеры (Quadlock→ISO, Fakra→SMA) без пайки** — сохраняет гарантию, надежнее
3. **LVDS кабель — не гните радиусом менее 30 мм**, не кладите рядом с высоковольтными/силовыми проводами
4. **Заземляйте корпус Box модуля** на кузов (короткий провод 1.5 мм²) — убирает шумы, стабилизация тача
4. **Тестируйте все функции ПЕРЕД сборкой панели** — экономьте часы повторной разборки
5. **Сохраните бэкап прошивки/настроек** перед любыми экспериментами (SD/USB/ADB pull)
