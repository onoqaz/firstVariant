# 05. Библиотека неисправностей

Дело не пишется вручную целиком — оно **собирается конструктором** из пяти компонентов:

```
ДЕЛО = Причина × Система × Проявление × Обманка × Контекст
```

Такая сборка даёт сотни уникальных кейсов из компактных таблиц и гарантирует,
что каждое дело физически согласовано: причина действительно порождает заявленные
показания приборов.

## Причины (физика отказа)

| ID | Причина | Что происходит в модели цепи |
|---|---|---|
| F01 | Перегоревший предохранитель | разрыв после предохранителя; ток = 0 |
| F02 | Жучок вместо предохранителя | цепь живёт без защиты; при КЗ — дым, оплавление жгута |
| F03 | Окисление контакта разъёма | скачок сопротивления 0.5–5 Ом; просадки под нагрузкой |
| F04 | Окисление точки массы | падение напряжения на массе 0.3–1.2 В под нагрузкой |
| F05 | Обрыв провода (перетирание) | обрыв «на вибрации»: контакт то есть, то нет |
| F06 | Обрыв провода (грызун) | устойчивый обрыв + следы в жгуте; часто два провода сразу |
| F07 | КЗ на массу | ток растёт, предохранитель сгорает повторно после замены |
| F08 | КЗ между проводами жгута | ложные сигналы: включение одной цепи дёргает другую |
| F09 | Подгоревшие контакты реле | работает на холодную, отказывает на горячую |
| F10 | Залипшее реле | потребитель не выключается; тихий разряд АКБ |
| F11 | Износ щёток мотора | работает через толчки; отказ по мере нагрева |
| F12 | Межвитковое КЗ обмотки | потребляет сверх нормы, греется, выбивает защиту |
| F13 | Утечка через доп. оборудование | паразитный ток 40–200 мА при «спящей» машине |
| F14 | Масса доп. оборудования «на болт пластика» | помехи, случайные срабатывания, недозаряд |
| F15 | Влага в разъёме | токи утечки между пинами; симптомы плавающие |
| F16 | Вода в блоке/ЭБУ | блок теряет связь периодически; коррозия прогрессирует |
| F17 | Сульфатация АКБ | ёмкость упала; холодный пуск слабый; напряжение проседает |
| F18 | Обрыв терминатора CAN | сопротивление шины 120 Ом вместо 60; модули отваливаются |
| F19 | Окисление пинов разъёма ЭБУ | intermittent-связь, «глюки» без закономерности для клиента |
| F20 | Забытый разъём (после ремонта) | полный отказ узла/шины; история ремонта скрыта |
| F21 | Обрыв проводки датчика | фиксированное значение датчика (например, лямбда 0.45 В) |
| F22 | Замерзающий датчик (вода во впуске) | отказ строго ниже порога температуры |
| F23 | Недозаряд генератора (щётки/диоды) | 12.6–13.2 В на работающем двигателе; медленный разряд |
| F24 | Паразитная нагрузка (лампа багажника) | утечка ~25–30 мА; АКБ садится за неделю стоянки |
| F25 | Проскальзывание ремня генератора | недозаряд под нагрузкой (фары+печка), свист на холодную |
| F26 | Коррозия клемм АКБ | просадка на стартере; греется клемма |
| F27 | Износ кнопки/переключателя | срабатывание с n-го раза; окислы внутри |
| F28 | Помехи неэкранированной проводки доп. оборудования | фантомные сигналы датчиков, шум на осциллографе |

## Проявления

Что именно наблюдают клиент и диагност:

| Группа | Примеры |
|---|---|
| Полный отказ | «не работает вообще», узел молчит |
| Частичный | «работает через раз», «с n-го раза» |
| Деградация | тусклый свет, медленный подъём стекла, слабый сигнал |
| Нестабильность | мерцает, глохнет, перезагружается панель |
| Паразитное поведение | сам включается, щёлкает реле ночью, жужжит насос |
| Защитный отказ | предохранитель горит повторно, выбивает при включении |
| Сетевые симптомы | ошибки по всем блокам, «мёртвый» сканер, панель в дауне |
| Энергетические | сел за ночь, крутит вяло на холодную, свист ремня |
| Чувственные улики | запах гари, дым, треск, тепло на разъёме |

## Обманки

Правдоподобные ложные следы, которые вводят в заблуждение (по образцу примеров модуля 20):

| Обманка | На что намекает | Реальность |
|---|---|---|
| P0420 (катализатор) | менять катализатор | обрыв провода лямбды (F21) |
| «Умер ЭБУ» | заказ блока | вода в разъёме (F16) или плохая масса (F04) |
| «Нужен новый АКБ» | замена батареи | утечка тока (F13/F24/F10) |
| P0300 пропуски | свечи/катушки | влага или CAN-обрыв (F15/F18) |
| «Иммобилайзер умер» | дорогой ремонт блока | забытый разъём шлюза (F20) |
| Следы кустарной прошивки | «глючит софт» | окисленные пины ЭБУ (F19) |
| Свист «ремня» | заменить ремень | недозаряд от щёток (F23) |

Обманка добавляется к делу начиная со ступени 4 и всегда физически честна:
она исчезает, если игрок доводит измерения до конца.

## Контекстные модификаторы

| Модификатор | Влияние |
|---|---|
| Сезон | зима: F17/F22/F26 чаще; лето: F13/F14; весна/осень: F15/F16 |
| Погода дня | дождь включает проявление влаги уже в день визита |
| Архетип клиента | меняет полноту анамнеза и лимиты времени (см. 02) |
| История ремонта | «была мойка/ДТП/установка музыки» — открывает сценарии A/B/C |
| Возраст машины | до 2000: больше простых причин; после 2010: CAN и электроника |
| Букет Толика | 1–3 лишних заменённые детали маскируют истинную картину |

## Правила совместимости при генерации

1. Одна причина может поражать несколько систем только через общие точки
   (масса двигателя, главный предохранитель, CAN) — иначе multi-system физически необъяснима.
2. Intermittent-причины (F05, F09, F15, F19, F22) требуют в деле условия воспроизведения;
   если игрок его не узнал при опросе, дебриф отдельно разбирает этот промах.
3. Обманка не должна указывать на вторую реальную причину дела — иначе решение неоднозначно.
4. Уровень 1–2 использует по одной причине; уровень 4 — две; финал — три.
5. Для каждой пары «система × причина» заранее описаны эталонные показания всех инструментов —
   это данные, а не логика: движку остаётся только отдавать их по запросу игрока.

## Пример сборки

**Шаг 1.** Выбираем ступень 3 → алгоритм 2, одна причина, сканер доступен.

**Шаг 2.** Причина: F10 (залипшее реле). Система: вентилятор печки (модуль 07).

**Шаг 3.** Проявление: паразитное поведение — «иногда ночью что-то жужжит в машине,
утром АКБ слабее». Контекст: лето, клиент — курьер (экономный, время ограничено).

**Шаг 4.** Обманка: нет (ступень 3). Но добавляем правдоподобный шум: старый АКБ
с лёгкой сульфатацией (F17 в фоновой версии) — чтобы замер напряжения покоя давал 12.4 В
и наводил на мысль о батарее.

**Шаг 5.** Эталонные данные: утечка 3.8 А (!) пока реле залипло; прозвонка управления —
сигнал с ЭБУ отсутствует, значит реле не «управляется», а заклинено; снятие реле K7
мгновенно обнуляет утечку. Правильная траектория: опрос → замер утечки → изоляция
предохранителей → реле K7 → замена. Дешёвая траектория существует и отмечается в дебрифе.
