# «МЕТÓД» — игра-симулятор диагностики автоэлектрики

> Текстовая игра-детектив: ты — автоэлектрик, и каждая машина — загадка со скрытой причиной.
> Игра учит не угадывать, а **методично локализовать неисправность** — по алгоритмам модуля 20 курса.

## Суть в одном абзаце

Игрок принимает заказы в автосервисе: у каждой машины скрытая неисправность (или несколько),
о которой известны только симптомы. Действия стоят игрового времени и денег, замены деталей вслепую
убивают репутацию. Победа — найти первопричину минимальными средствами и подтвердить ремонт проверкой.
Оценивается **ход диагностики**, а не финальный ответ: игра прямо тренирует алгоритмы
«опрос → осмотр → питание → масса → управление → компонент → ремонт → проверка».

## Источник знаний

Вся предметная база взята из курса «курс по автоэлектрике», прежде всего:

- `Module_20_Алгоритмы_диагностики_неисправностей.md` — три алгоритма, чеклисты, правила,
  реальные случаи (лёгли в основу боссовых дел);
- модули 01–18 — физика цепей и конкретные системы для библиотеки неисправностей;
- `Module_19_Эпичные_ошибки_автоэлектриков.md` — антипримеры для механики «пушки запчастей».

## Формат

Текст/ASCII (ядро игры не требует графики). Позже возможна 2D-оболочка поверх того же ядра.
Статус: дизайн-документ v1.

## Реализация (прототип)

Папка содержит рабочий текстовый прототип `metod.py` (Python 3.10, без зависимостей).

```
python3 "игра Метод/metod.py"
```

Что уже работает из дизайна:
- цикл дела «опрос → осмотр → измерения → гипотеза → ремонт → верификация»;
- ресурсы время / заряд АКБ / репутация / деньги;
- инструменты: опрос, осмотр зон, мультиметр (U/R/drop/утечка), сканер, изоляция;
- три сыгранных дела (ступени 1–3): стеклоподъёмник, мерцающие фары, ночная утечка;
- анти-механика «пушки запчастей» (штраф за слепую замену, блокировка верификации);
- дебриф с покрытием чеклиста и подсчётом очков по формуле из модуля 03.

Что заглушено (требует доработки):
- генератор дел из таблиц 05 (сейчас дела заданы вручную в `CASES`);
- стенд условий / термоспрей, осциллограф, выезды, экзамен акта 5;
- мета-прогресс, журнал дяди Славы, сюжетные акты и боссовые дела 04;
- 2D-оболочка и сохранения.

Расширение: добавь новый словарь в `CASES` по шаблону существующих —
модель дела декларативна, движок переиспользуется без изменений.
