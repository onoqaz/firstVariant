# «МЕТÓД» — игра-симулятор диагностики автоэлектрики

> Текстовая игра-детектив: ты — автоэлектрик, и каждая машина — загадка со скрытой причиной.
> Игра учит не угадывать, а **методично локализовать неисправность** — по алгоритмам модуля 20 курса.

## Суть в одном абзаце

Игрок принимает заказы в автосервисе: у каждой машины скрытая неисправность (или несколько),
о которой известны только симптомы. Действия стоят игрового времени и денег, замены деталей вслепую
убивают репутацию. Победа — найти первопричину минимальными средствами и подтвердить ремонт проверкой.
Оценивается **ход диагностики**, а не финальный ответ: игра прямо тренирует алгоритмы
«опрос → осмотр → питание → масса → управление → компонент → ремонт → проверка».

## Источник знаний

Вся предметная база взята из курса «курс по автоэлектрике», прежде всего:

- `Module_20_Алгоритмы_диагностики_неисправностей.md` — три алгоритма, чеклисты, правила,
  реальные случаи (лёгли в основу боссовых дел);
- модули 01–18 — физика цепей и конкретные системы для библиотеки неисправностей;
- `Module_19_Эпичные_ошибки_автоэлектриков.md` — антипримеры для механики «пушки запчастей».
